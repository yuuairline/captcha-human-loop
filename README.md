# Captcha Human Loop

Минимальный сервер + операторская панель для human-in-the-loop решения CAPTCHA.
Используется вместе с userscript: при обнаружении CAPTCHA userscript отправляет задачу на сервер,
оператор отмечает задачу как решённую после ручного решения (в той же сессии/браузере).

## Запуск сервера (локально)
1. Установи Node.js (v16+ рекомендовано).
2. npm install
3. API_KEY=твой_секрет node server.js
4. Открой http://localhost:3000 — панель оператора.

## API
- POST /api/report — создать задачу (X-Api-Key обязателен)
- GET /api/tasks — список задач
- GET /api/status/:id — статус конкретной задачи
- POST /api/tasks/:id/mark_solved — пометить решённой
- POST /api/tasks/:id/mark_dismissed — отклонить

## Примечания
- Для корректной работы CAPTCHA решение должно происходить в той же сессии/IP, где форма отправляется.
- Не пытаться автоматически обходить CAPTCHA — это нарушает правила.
